Ceno Manual

Pourquoi devenir une passerelle Ceno ?

Un réseau pair à pair est construit à partir de chacun des nœuds qui y sont connectés (oui, ça veut dire vous aussi !). Plus il y a de nœuds, plus robuste et versatile le réseau sera.

Si vous lancez le navigateur Ceno depuis un pays qui ne censure pas Internet (ou pas aussi lourdement que certains), envisagez d'aider d'autres utilisateurs de Ceno en devenant une passerelle. Vous commencerez alors à gérer le trafic entre les clients vivant dans des pays fortement censurés et les injecteurs de Ceno.

Vous ne serez pas en mesure de voir leur trafic (il sera envoyé à travers un tunnel crypté), pas plus que des traces de ce trafic ne resteront sur votre appareil.

Note : La configuration décrite dans cette section peut également aider votre appareil à partager efficacement le contenu vers d'autres sur le cache distribué, alors veuillez envisager de l'appliquer aussi bien lors de l'utilisation de Ceno dans un pays pratiquant la censure (mais garder à l'esprit les [risks] (https://ceno.app/en/faq.html#bridgemode) de donner accès à ce contenu à d'autres)

Comment devenir une passerelle de Ceno ?

Comme indiqué dans [this section] (./public-or-personal.html#bridges), l'application Ceno fournit certaines fonctionnalités qui vous permettent de devenir facilement une passerelle Ceno, si votre configuration réseau le permet.

Si vous avez vérifié votre Reachability et votre statut UPnP status et il ressemble à ceci

Vous devrez configurer votre routeur en permettant UPnP ou en configurant la redirection de port. Dans les sections suivantes, nous décrivons les étapes à suivre.

Activer l’UPnP sur votre routeur Wi-Fi

UPnP est la meilleure façon de rendre votre navigateur Ceno (ou client de bureau) accessible au réseau Ceno.

Note : L'activation de UPnP sur le routeur Wi-Fi peut exposer des dispositifs sur votre réseau à des interférences externes. Veuillez prendre connaissance des risques (https://www.howtogeek.com/122487/htg-explains-is-upnp-a-security-risk/) et envisager d'utiliser d'autres méthodes comme expliqué ci-dessous

La première chose à faire est de vous connecter à l'interface web de votre routeur. Pour savoir comment faire, veuillez consulter le manuel de votre routeur qui vous indiquera quel utilisateur et mot de passe utiliser pour vous connecter.

Après cela, les étapes à effectuer sont similaires, mais peuvent ne pas être identiques pour tous les modèles de routeur.

Voici un bel article avec des instructions étape par étape pour activer UPnP sur différents routeurs.

Veuillez trouver les instructions pour votre type de routeur et effectuer les étapes nécessaires.

Si vous préférez, cependant, vous pouvez choisir de configurer la redirection de port au lieu de l'UPnP.

Utilisez la redirection de port comme alternative à UPnP

La première étape est la même qu'avant : connectez-vous à l'interface web du routeur.

Ensuite, veuillez localiser l'option redirection de port.

Pour voir vers quelle adresse IP vous devez transférer les connexions et le port pertinent, ouvrez la page ** Paramètres Ceno** et regardez sous les paramètres UDP locaux.

La redirection de port doit concerner le protocole UDP (pas TCP).

Ceno choisit un port aléatoire en première exécution et le conserve pour les exécutions ultérieures, mais l'adresse IP réseau local de votre appareil peut changer de temps à autre. Vous devriez donc revoir périodiquement la page Paramètres Ceno pour voir que votre appareil est accessible au réseau Ceno.

Votre appareil est accessible si son

Le statut d'accessibilité est ** probablement accessible** ou accessible

** Le status UPnP** est activé

** Note technique** : Sinon, vous pouvez vous assurer que le routeur attribue toujours la même adresse IP à votre appareil (p. ex. via un bail DHCP statique pour l'adresse MAC du périphérique)

Si vous avez un ordinateur avec une bonne connexion qui reste la plupart du temps allumé, et vous souhaitez le configurer comme une passerelle Ceno, veuillez continuer à lire.

Faire tourner un pont sur un ordinateur

Si votre ordinateur supporte les conteneurs Docker, vous pouvez lancer un client Ceno préconfiguré sur celui-ci pour agir comme une passerelle. Si Docker n'est pas encore installé, veuillez suivre les instructions pour installer le moteur Docker dans votre plateforme. Pour les dérivés Debian comme Ubuntu ou Linux Mint, vous pouvez simplement lancer : sudo apt install docker.io

Pour déployer un conteneur client Ceno, il vous suffit d’exécuter la commande suivante dans un terminal (n’ayez pas peur, il vous suffit de la copier et de la coller telle quelle sur la ligne de commande) :

sudo docker run --name ceno-client \
  -dv Ceno:/var/opt/ouinet --network host \
  --restart unless-stopped equalitie/Ceno-client

Si le système d’exploitation de votre ordinateur n’est pas fondé sur GNU/Linux, la commande doit être légèrement différente :

sudo docker run --name ceno-client \
  -dv ceno:/var/opt/ouinet \
  -p 127.0.0.1:8077-8078:8077-8078 -p 28729:28729/udp \
  --restart unless-stopped equalitie/ceno-client

La commande va démarrer un conteneur nommé ceno-client qui fonctionnera sur chaque démarrage, à moins que vous lui disiez explicitement d'arrêter.

Veuillez consulter la Ceno Docker documentation client pour plus d'informations sur la façon de manipuler le conteneur.
