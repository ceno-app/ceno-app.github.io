3. Notice de confidentialité

Cette section est utilisée pour informé les visiteur de la politique d'eQualities concernant la collecte de données, leur utilisation et la divulgation d'information personnelle pour tous les utilisateurs de ce service.

3.1 Collecte de données

Le navigateur Ceno est conçu avec la vie privée à son cœur et n'exige aucune information d'identification personnelle pour fonctionner. Vous n'avez pas besoin de fournir un nom, un identifiant d'utilisateur, un pseudo, un compte ou toute autre donnée personnelle pour utiliser l'application. eQualitie ne sait pas qui utilise Ceno, ni avec qui les utilisateurs synchronisent ou partagent du contenu.

Nous respectons votre vie privée et ne collectons que des données anonymisées pour améliorer l'application. Cette information est filtrée de tout élément permettant une identification individuelle avant collecte, et n'est jamais partagée avec des tierces parties.

Par défaut, Ceno collecte des données d'usage anonymisées en utilisant notre propre, auto-hébergé, serveur d'analyses. Ce processus est conçu pour préserver la vie privée :

  • Les adresses IP ne sont pas stockées
  • Aucune information personnelle n'est collectée
  • Les données sont associées avec un identifiant d'appareil généré aléatoirement
  • L'identifiant généré aléatoirement n'est pas associé avec des identifiants utilisateur ou appareil (ex : IP, MAC, IMEI, MEID)
  • L'identifiant est remplacé avec un nouvel identifiant tous les 30 jours ou plus fréquemment
  • Les identifiants d'appareils aléatoires passés, présents et futures ne sont pas associés

Les données anonymisées suivantes peuvent être collectées :

  • Statistiques de réseau pair à pair, par exemple les volumes de données transférées, le nombre de connections aux pairs réalisés
  • Données de performance de l'application, par exemple le taux de succès des connexions et la latence
  • Statistiques d'usage de l'application, par exemple le temps passé sur les modes de navigation personnel et public
  • Pays dans lequel l'appareil est localisé (supposé. Aucune donnée GPS ou localisation exacte n'est envoyée)
  • Paramètres d'appareils relatifs au pays, langage et local
  • Si l'appareil utilise un VPN (mais pas plus d'information concernant le VPN)
  • Le nom de l'opérateur de service téléphonique (si applicable)

Note : la supposition du pays est basée sur le local de l'appareil, la présence d'un VPN, et les données de l'opérateur téléphonique.

Toutes les données collectées sont automatiquement supprimées après 90 jours. Les utilisateurs peuvent désactiver la collecte de statistiques à tout moment depuis les réglages de l'application.

Nous collectons des données de manière horaire, journalière et mensuelle pour nous aider à mesurer le nombre d'utilisateur, incluant le réseau ASN d'origine et le pays, basé sur la navigation en mode public.

Les injecteurs sont des serveurs qui peuvent voir des demandes de contenu sur le réseau, y compris l'adresse IP de l'utilisateur faisant la demande et le nom du domaine du site Web demandé. Les injecteurs sont une composante réseau nécessaire pour 1) introduire du contenu web dans un réseau décentralisé, et 2) authentifier l'intégrité du contenu introduit. Sur le réseau Ceno, les injecteurs sont administrés et gérés par l'équipe Ceno. eQualitie supprime tous les journaux d'accès toutes les 24 heures.

Les serveurs Bootstrap sont des serveurs utilisés pour introduire votre appareil sur le réseau BitTorrent. Nous envoyons les adresses IP des utilisateurs à nos serveurs de bootstrap auto-hébergés et aux serveurs de bootstrap tiers. Pour les serveurs auto-hébergés bootstrap, nous conservons les adresses IP dans un cache en mémoire. Les adresses IP sont vérifiées pour la réactivité de manière fréquent et sont retirées lorsqu'elles ne sont plus actives au trafic BitTorrent.

3.2 Partage des données

Le navigateur Ceno (et eQualities) ne partagent aucune données avec des tierces partis.

Cette application propose deux modes de fonctionnement -Public etPersonnel.

Les onglets Public utilisent toutes les méthodes de connectivité disponibles dans le réseau Ceno pour obtenir le contenu souhaité. Lors de la navigation en utilisant un onglet public, les utilisateurs laisseront un enregistrement de leur activité sur le réseau public BitTorrent (adresse IP et site Web demandés). Le contenu qui a été récupéré par un appareil d'utilisateur dans un onglet public sera partagé avec d'autres utilisateurs de Ceno via le réseau BitTorrent.

Dans le mode Personnel, vous ne contacterez les Injecteurs que pour que ce site soit fétiché et livré à vous. La recherche ne se connectera pas au réseau BitTorrent et ne tentera pas de localiser le contenu sur les appareils d'autres utilisateurs.

Pour que votre client Ceno puisse toujours contacter un injecteur, nous avons également créé des Passerelles. Si les Injecteurs sont bloqués sur votre réseau, l'application Ceno cherchera les Passerelles disponibles, qui transmettront la demande d'un utilisateur aux Injecteurs. Les utilisateurs peuvent autoriser l'activation du mode passerelles dans Ceno Browser pour améliorer l'accessibilité du contenu Web pour d'autres. L'activité de la passerelle est invisible pour l'opérateur de la passerelle (sauf s'ils surveillent activement leur dispositif pour les connexions entrantes et sortantes). Leur travail consiste à recevoir des demandes de réseau d'autres utilisateurs de Ceno pour accéder à un Injecteur et transmettre cette demande. Les exploitants de passerelles auront l'adresse IP de leur appareil indiquée dans le réseau BitTorrent en tant que passerelle accessible.

3.3 Données de connexion

Les utilisateurs peuvent opter pour la connexion via le menu Paramètres dans le navigateur Ceno. Lorsque activé, le navigateur Ceno crée des fichiers journaux sur les périphériques de l'utilisateur. L'objectif de ces fichiers est seulement de loger l'activité de l'appareil pour faciliter le processus de débogage dans le cas où un utilisateur éprouve des difficultés à se connecter avec ses pairs ou autrement à utiliser Ceno. Le fichier journal reste sur le périphérique d'un utilisateur à moins que l'utilisateur ne décide de nous l'envoyer à des fins de support, et est automatiquement supprimé lorsque sa taille atteint 15 Mo.

Si l'utilisateur décide de nous contacter, les données d'identification personnelles que nous pouvons collecter sont :

  • Adresse mail - si l'utilisateur décide de nous contacter par mail ;
  • Information que l'utilisateur peu fournir par mail, par les tickets de support, ou par les sites web de eQualities, et ces méta-data associées - dans l'objectif de fournir un support technique ;
  • Activité de navigation internet et historique.

Aucune de ces données n'est partagée avec une tierce partie.

3.4 Rapport de plantage

Les utilisateurs peuvent opter pour la déclaration de crash via le menu Paramètres dans le navigateur Ceno. Lorsque activé, le navigateur Ceno enverra des rapports de crash en cas de problème lors de l'exécution de l'application. Les rapports de crash sont transmis automatiquement à un serveur géré par eQualitie. Nous utilisons Sentry pour la déclaration de crash.

Sentry conserve les données d'événements en production pendant 90 jours. Les événements individuels sont regroupés en questions plus larges et sont supprimés après la période de conservation ci-dessus. Les questions sont supprimées lorsque tous les événements associés sont supprimés.

4. Glossaire

Bootstrap Servers: Les serveurs utilisés pour aider votre appareil à accéder au réseau BitTorrent.

Bridges: Serveurs (y compris les appareils d'utilisateurs si le mode pont est activé) utilisant Ceno Browser qui servent à l'acheminement des requêtes de contenu web si d'autres mécanismes de connectivité sont inaccessibles ou indisponibles.

Injecteurs: Les serveurs exécutent par eQualitie que routent le contenu web des serveurs d'origine vers les appareils d'utilisateurs Ceno demandant ce contenu.

Mode personnel: L'activité de croissance en mode personnel n'est partagée avec personne d'autre. Le contenu Web est récupéré en toute sécurité depuis l'origine ou via Injectors.

Mode public: L'activité de navigation en mode public utilise toutes les méthodes de connectivité disponibles pour récupérer le contenu Web du réseau Ceno, partage ce contenu avec d'autres utilisateurs Ceno via le réseau BitTorrent et laisse un enregistrement public de l'adresse IP et du contenu de votre appareil récupérés.
